# Claude Change Log

This file records significant feature changes, bug fixes, and refactors made with the help of Claude Code. Each entry is dated and scoped to a single topic. Small trivial edits (typo fixes, whitespace, unrelated tweaks) are not logged here — commits alone are enough for those.

Newest entries on top.

## 2026-04-16 — Add bilingual README, one-line installer, and release workflow

- Added `README.md` (English, default) and `README.zh-CN.md` (Chinese) with shields.io language-switcher badges at the top of each.
- Added `install.sh` — one-liner installer that detects OS (linux/darwin) and arch (amd64/arm64), fetches the latest release tag via the GitHub API, and drops the binary into `~/.local/bin` (override with `INSTALL_DIR=`).
- Added `.goreleaser.yaml` + `.github/workflows/release.yml` — on `v*` tag push, builds linux/macOS/windows × amd64/arm64 archives via GoReleaser v2 and attaches them to the GitHub Release. Archive naming matches what `install.sh` expects.
- Introduced the change-log convention itself: `.claude_change_log.md` at the repo root + a `Change log` section in `CLAUDE.md` describing when to append entries.
- **Touched:** `README.md`, `README.zh-CN.md`, `install.sh`, `.goreleaser.yaml`, `.github/workflows/release.yml`, `.claude_change_log.md`, `CLAUDE.md`

## 2026-04-16 — Refine card rank block font

- Switched to a 3-line block font for card ranks so the rank is legible on the enlarged 18×14 card. Digits reuse the `bignum.go` style; added hand-drawn `A / J / Q / K` glyphs.
- Fixed the `J` glyph — the old bottom row `▀▀ ` drew the hook in the upper half of the row, leaving it floating above the baseline. Replaced with `▄█▀`, which gives a diagonal "swoosh" that connects the stem to a grounded hook.
- **Touched:** `ui/components/card.go`

## 2026-04-16 — Enlarge the card rank digits

- The earlier card-size bump (9×7 → 18×14) left the rank as a single tiny character in the corner. Added a 3-line tall block font and repositioned the rank in both the upper-left and lower-right corners of each card; the centered suit symbol is untouched.
- Added `rankGlyphs` table + `renderRankGlyph` helper in `card.go`; reworked `buildCardLines` to lay out three rows of rank glyph + middle suit + three mirrored rows at the bottom.
- **Touched:** `ui/components/card.go`
